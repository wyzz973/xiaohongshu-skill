# XHS Autopilot 用户操作手册

## 两种使用模式

| 模式 | 适用场景 | 特点 |
|------|---------|------|
| **自动驾驶** | 日常持续运营，7×24 小时 | Cron 定时执行，agent 自主决策，无需干预 |
| **手动驾驶** | 随时指令，按需操作 | 对话触发，每步确认，完全可控 |

两种模式共享同样的能力深度——自动模式不需确认，手动模式每步确认。

---

## 快速开始

### 前置要求

- Python 3.11+、Chrome 浏览器
- OpenClaw 平台（自动驾驶需要）或 Claude Code（手动驾驶即可）

### 首次设置

```
你：帮我设置小红书自动运营
```

系统会引导你完成 5 组配置：

1. **账号定位** — 你的赛道是什么？细分方向？一句话定位？
2. **人设风格** — 什么人设类型？语言风格？emoji 使用习惯？
3. **运营策略** — 发布频率？时间？内容支柱有哪些？
4. **目标受众** — 面向什么人群？他们的痛点？
5. **安全设置** — 发布前是否需要你确认？每日互动限额？

配置完成后自动生成 `strategy.json` 并注册定时任务。

## 自动驾驶模式

设置完成后，系统按以下时间表自动运行：

```
07:00  选题调研 ── 搜热帖 → 拆解爆款 → 搜最新资讯 → 生成选题卡片
09:00  内容创作 ── 对标爆款写内容 → 三层校验（质量/对标/合规）→ 保存草稿
10:00  发布笔记 ── 检查登录 → 取草稿 → 发布（如需确认则等你回复）
14:00  互动巡逻 ── 刷推荐流 → 去重 → 发评论/点赞 → 记录
16:00  二次发布 ── 可选，同 10:00 流程
20:00  通知互动 ── 处理评论回复 → 防重复 → 智能回复
22:00  数据复盘 ── 采集数据 → 分析漏斗 → 自动调整策略
02:00  登录巡检 ── 检查 cookies → 异常通知
```

### 你只需要做的事

**日常：什么都不用做**。系统全自动运行。

**偶尔：看看日报**
```
你：看看这周数据
→ 系统展示笔记排行、涨粉趋势、内容表现分析
```

**需要时：调整方向**
```
你：换赛道，改做美食                    ← 修改账号定位
你：修改发布时间到晚上 8 点              ← 调整排期
你：暂停自动互动                        ← 暂停某个任务
你：查看运行状态                        ← 检查 Cron 状态
```

### agent 会自动进化什么

每天 22:00 数据复盘后，agent 会根据数据自动调整：

| 自动调整 | 示例 |
|---------|------|
| 内容支柱权重 | "教程类 CTR 21%，权重从 0.2 提到 0.4" |
| 选题关键词 | "加入高 CTR 笔记的选题词" |
| 标签候选池 | "保留高互动标签，淘汰无效标签" |
| 发布时间 | "12:00 发的互动比 10:00 高 3 倍，调整到午间" |
| 互动限额 | "近期无风控信号，适当提高限额" |
| 审核红线 | "从被拒笔记学到：不能拉踩竞品" |

**不会自动改的**（只有你能改）：赛道方向、人设风格、语言风格、安全设置。

## 手动驾驶模式

随时对 agent 说以下指令即可。

### 创作发布（完整流程）

```
你：帮我写一篇关于 Claude Code 的笔记
```

agent 会完整执行：
1. **深度调研** — 搜热帖 → 拆解 3-5 篇爆款正文+评论区 → WebSearch 最新资讯
   → 向你报告："发现这些爆款模式和时效性素材，建议这个切入角度，你觉得呢？"
2. **对标创作** — 生成 5 个标题候选（标注模仿了哪个爆款）→ 你选一个
   → 生成正文 → 你确认或修改
3. **三层校验** — 检查内容质量/爆款对标/合规 → 向你报告结果
4. **发布** — fill-publish → 你在浏览器确认预览 → click-publish

### 直接发布（已有内容）

```
你：帮我发布这篇（附上标题+正文+图片）
```

跳过调研和创作，直接进入发布流程。

### 搜索浏览

```
你：搜索小红书上关于 AI 工具的帖子
你：看看这篇帖子的详情（附链接或 ID）
你：看看首页推荐
你：看看美食板块
```

### 互动

```
你：帮我评论这篇帖子
你：帮我回复这条评论
你：帮我点赞这篇
```

agent 会先生成评论内容，你确认后才发送。

### 数据分析

```
你：看看我的数据
→ 展示笔记排行表：每篇的曝光/CTR/观看时长/涨粉
→ 账号总览：7 日数据+环比+同类百分位排名
→ 改进建议

你：哪篇最火？
→ 按观看/涨粉/互动排序展示

你：粉丝是什么人？
→ 性别/年龄/兴趣/地域分布

你：这周涨粉了吗？
→ 粉丝趋势 + 环比变化
```

### 审核诊断

```
你：那篇审核没过，为什么？
→ 展示被拒原因：违规标签 + 详细原因 + 平台修改建议
→ agent 建议修改方向
```

### 账号管理

```
你：检查登录状态
你：切换到工作号
你：添加一个新账号叫"小号"
你：列出所有账号
```

## 多账号使用

每个账号独立隔离（独立 Chrome Profile + 独立端口）。

```
你：添加一个新账号叫"work"
→ 系统分配端口 9223，创建独立 Chrome Profile

你：用 work 账号搜索 AI 工具
→ 自动切换到 work 账号执行

你：列出所有账号
→ 展示所有账号及其端口、是否默认
```

所有命令都支持指定账号，或在多账号时自动询问你要用哪个。

## 安全须知

- **强烈建议先用小号测试**，确认效果后再用主号
- 发布类操作默认需要你确认（`safety.require_publish_confirmation = true`）
- 互动频率有硬限制（评论每日 20-25 条，点赞 40-50 次），不可突破
- 风控信号（验证码/频率限制）触发时自动停止并通知你
- 夜间 02:00-06:00 自动休眠，不执行互动操作
- agent 不会自动修改你的赛道和人设，这些只有你能改
