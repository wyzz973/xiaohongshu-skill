# 小红书表情参考

在评论/回复中插入 `[表情名]` 即可，发送后自动渲染。

## 使用原则

- 约 50-70% 的评论带表情，一条最多 1-2 个
- 位置灵活：句末居多，也可句中穿插
- 根据语境选择，不要硬塞

## 常用表情

| 场景 | 推荐 |
|------|------|
| 认同 | `[赞R]` `[点赞R]` `[okR]` `[鼓掌R]` |
| 开心 | `[笑哭R]` `[大笑R]` `[偷笑R]` `[哇R]` |
| 可爱 | `[飞吻R]` `[萌萌哒R]` `[害羞R]` `[吧唧R]` |
| 思考 | `[吃瓜R]` `[暗中观察R]` `[黑薯问号R]` `[看R]` |
| 无奈 | `[捂脸R]` `[叹气R]` `[汗颜R]` `[可怜R]` |
| 加油 | `[加油R]` `[火R]` `[拳头R]` `[举手R]` |
| 种草 | `[种草R]` `[买爆R]` `[红色心形R]` `[爱心R]` |
| 调皮 | `[doge]` `[斜眼R]` `[抠鼻R]` `[得意R]` |

## 示例

- "这个方法太实用了[赞R]" — 认同型
- "哈哈确实[笑哭R]之前我也踩过这个坑" — 共鸣型
- "说得对[doge]不过我觉得还可以再加个..." — 调皮补充型
