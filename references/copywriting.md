# 小红书文案参考手册

## 标题公式

为每篇内容生成5个备选标题，每个用不同公式：

| 公式 | 示例 |
|------|------|
| 数字冲击 | 坚持这5个习惯30天，同事问我是不是去医美了 |
| 反差对比 | 月薪5k的穿搭，被问是不是月薪5w |
| 痛点直击 | 英语听力总是听不懂？不是你笨，是方法错了 |
| 身份背书 | 做了8年设计师，这些排版技巧我不允许你不知道 |
| 好奇悬念 | 找到了XXX的平替！价格只要1/10 |
| 情绪爆发 | 求你们别再这样护肤了！烂脸都是自己作的！ |
| 对话体 | 姐妹听我说，这玩意儿真的绝了 |
| 清单体 | 学生党平价护肤全攻略（附产品清单） |

规则：18-25字，含1-2个搜索关键词，感叹号/句号结尾（比问号点击率高）。

## 开头 Hook

前两句决定用户是否继续读。绝不用"大家好今天给大家分享"。

**痛点型**：你是不是也[痛点]？别慌，我之前也是...
**反常识型**：99%的人都在做的[行为]，其实是错的
**数字型**：花了[金额/时间]踩坑，总结出这[数字]条经验
**悬念型**：发现了一个[领域]的bug...
**故事型**：上周发生了一件事，让我彻底改变了对[话题]的看法
**权威型**：做了[年数]年[职业]，有些话不得不说

## 正文模板

### 教程/干货型
```
[Hook]
📌 先说结论：[核心方法]
很多人[错误做法]，其实[正确理解]
✅ 方法一：[名称] — [1-2句+个人体验]
✅ 方法二：[名称] — [1-2句+个人体验]
✅ 方法三：[名称] — [1-2句+个人体验]
⚠️ 注意避坑：[容易犯的错误]
最后说一句，[总结+鼓励]
[互动引导]
```

### 种草/测评型
```
[Hook：结果展示]
先说使用感受：[一句话总结]
🔍 我的情况：[个人背景，增加参考性]
💡 使用体验：[时间+场景+具体感受+对比变化]
✨ 优点：[具体到场景]
😅 不足：[诚实说明+应对方法]
📝 总结：适合[人群]，不适合[人群]
[互动引导]
```

### 合集/清单型
```
[Hook：数字+价值承诺]
整理了[数字]个[主题]，建议先收藏📌
1️⃣ [项目] — [1句理由+1句场景] 💰[价格]
2️⃣ [项目] — [1句理由+1句场景] 💰[价格]
...
🏆 如果只选一个：[最推荐+原因]
[互动引导]
```

## 视频 HOOK（前3秒）

**冲突型**：所有人都让你[常见建议]，但这完全是错的
**痛点型**：如果你也[痛点]，你一定要听我说完
**结果型**：看到最终效果了吗？教你怎么做到
**好奇型**：今天分享一个90%的人不知道的技巧
**情绪型**：我终于忍不住要说了

## CTA 收尾话术

**收藏导向**：信息量有点大，建议先📌收藏，需要的时候翻出来看～
**评论导向**：你们有遇到过类似的情况吗？评论区聊聊～
**关注导向**：后面还会持续更新，不想错过的话记得关注

## 话题标签三层结构

- **大流量层**（3-4个）：赛道大类标签，搜索热度高
- **精准层**（4-6个）：细分领域标签，目标用户会搜的词
- **长尾层**（3-5个）：具体场景词、特定人群词

## 去 AI 味指南

**结构上**：
- ❌ 总分总、首先其次最后、每段等长
- ✅ 直接切入，长短交替，有的段落就一句话

**用词上**：
- ❌ "值得一提的是""不得不说""众所周知""总而言之"
- ✅ 口语化，像微信聊天

**细节上**：
- 加不完美表达："说实话我也不太确定""可能因人而异哈"
- 加具体时间地点："上周三下午""在地铁上刷到的"
- 加情绪波动："一开始真的很绝望""后来突然开窍了"
- 用省略号和破折号制造口语节奏

**节奏上**：
- 偶尔用一个字段落："绝了。""真的。""冲！"
- 括号补充内心OS："（不是广告真的自己买的）"

## 评论话术（自动化评论用）

按类型各备3-5条，根据具体笔记内容修改细节，不可原样复制：

**共鸣型**：天呐太真实了，我[具体经历]的时候也是这样！
**补充型**：补充一个小技巧：[在原笔记基础上的额外信息]，亲测有效～
**提问型**：[具体产品/方法]对[我的情况]也适用吗？好想试试！
**引流型**：关于这个话题我之前研究了很久，有兴趣可以看我主页～

每条评论必须过三关：真人会自然说出这话吗？去掉账号名看起来像营销号吗？笔记作者看到会反感吗？
